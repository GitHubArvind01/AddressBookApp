# AddressBookApp

A simple Address Book application created to manage contact details in one place.

## Purpose

This repository is for practicing and demonstrating basic application development concepts such as creating, viewing, updating, and deleting address book records.

## Features

- Add new contacts
- View saved contacts
- Update contact details
- Delete contacts
- Maintain basic address book information

## Project Use

This project is useful for learning CRUD operations and understanding how a basic contact management application works.
